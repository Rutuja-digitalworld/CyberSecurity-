# TASK6-🌐 HTTP Request Headers — GitHub Notes

### 1. Request Headers

**Request Headers** → Extra information sent by the client/browser to the web server.

| Header           | Example                            | Meaning                                                                       |
| ---------------- | ---------------------------------- | ----------------------------------------------------------------------------- |
| **Host**         | `Host: tryhackme.com`              | Specifies the **domain name of the web server** the request is being sent to. |
| **User-Agent**   | `User-Agent: Mozilla/5.0`          | Tells the server information about the **browser/client** making the request. |
| **Referer**      | `Referer: https://www.google.com/` | Shows the **URL from which the request came**.                                |
| **Cookie**       | `Cookie: user_type=student`        | Contains information previously stored by the server in the browser.          |
| **Content-Type** | `Content-Type: application/json`   | Specifies the **format/type of data** being sent.                             |


---

# 📦 Request Body

The **Request Body** contains data sent **from the client to the server**.

Commonly used with:

* `POST`
* `PUT`

### Common Request Body Formats

#### 1️⃣ URL Encoded

**Content-Type:** `application/x-www-form-urlencoded`

Data is sent as **key=value pairs** separated by `&`.

```text
name=Aleksandra&age=27&country=US
```

⭐ **Remember:**
`key=value&key=value`

**Q. Default content type for form submissions using key=value format?**

➡️ **Answer: `application/x-www-form-urlencoded`**

---

#### 2️⃣ Form Data

**Content-Type:** `multipart/form-data`

Used when sending **multiple types of data**, especially **file uploads/images**.

```text
username = aleksandra
profile_pic = aleksandra.jpg
```

⭐ **Remember:** File upload → `multipart/form-data`

---

#### 3️⃣ JSON

**Content-Type:** `application/json`

Data is written as **name : value** inside `{ }`.

```json
{
  "name": "Aleksandra",
  "age": 27,
  "country": "US"
}
```

⭐ **Remember:** API requests commonly use JSON.

---

#### 4️⃣ XML

**Content-Type:** `application/xml`

Data is enclosed inside **opening and closing tags**.

```xml
<user>
    <name>Aleksandra</name>
    <age>27</age>
</user>
```

⭐ **Remember:** XML → `<tags>`

# 🧠 Most Important Q&A

### Q1. Which header specifies the domain name of the web server?

✅ **Host**

### Q2. Default content type for `key=value` form data?

✅ **application/x-www-form-urlencoded**

### Q3. Which part contains Host, User-Agent and Content-Type?

✅ **Request Headers**

## 🔥 Quick Memory Trick

```text
HOST       → Where am I sending?
USER-AGENT  → Who is sending?
REFERER    → Where did I come from?
COOKIE     → What information was stored?
CONTENT-TYPE → What type of data am I sending?
BODY       → Actual data being sent
```

### ⚡ One-line flow

**HTTP Request = Request Line + Headers + Blank Line + Body**
