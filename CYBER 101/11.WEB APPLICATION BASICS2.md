# 🌐 HTTP Response — Cybersecurity Notes

## 1. 📌 Status Line

The **Status Line** is the **first line of an HTTP response**.

It contains **3 important parts**:

```text
                    STATUS LINE
                         │
             ┌───────────┼───────────┐
             ▼           ▼           ▼
      HTTP VERSION   STATUS CODE   REASON PHRASE
             │           │           │
             ▼           ▼           ▼
          HTTP/1.1       200          OK
             │           │           │
             ▼           ▼           ▼
        HTTP version   Request      Short human-
                       result       readable meaning
```

### Example

```http
HTTP/1.1 200 OK
```

| Part              | Example    | Meaning                         |
| ----------------- | ---------- | ------------------------------- |
| **HTTP Version**  | `HTTP/1.1` | Version of HTTP being used      |
| **Status Code**   | `200`      | Result/outcome of the request   |
| **Reason Phrase** | `OK`       | Short explanation of the result |

### 📝 Exam Question

**Q. Which part of an HTTP response provides the HTTP version, status code and brief explanation?**

✅ **Answer: Status Line**

# 2. 🚦 HTTP Status Code Categories

HTTP status codes are **3-digit numbers** divided into 5 categories:

```text
                    HTTP STATUS CODES
                           │
       ┌──────────┬────────┼────────┬──────────┐
       ▼          ▼        ▼        ▼          ▼
     1xx        2xx      3xx      4xx        5xx
       │          │        │        │          │
       ▼          ▼        ▼        ▼          ▼
 INFORMATION   SUCCESS  REDIRECT  CLIENT     SERVER
                                ERROR       ERROR
```

| Code        | Category         | Meaning                                  |
| ----------- | ---------------- | ---------------------------------------- |
| **100–199** | 🟡 Informational | Request is being processed               |
| **200–299** | 🟢 Successful    | Request was successful                   |
| **300–399** | 🔄 Redirection   | Resource moved / another action required |
| **400–499** | ❌ Client Error   | Problem with the client's request        |
| **500–599** | 🔴 Server Error  | Problem occurred on the server           |

### 📝 Exam Question

**Q. Which category indicates that the web server encountered an internal issue?**

✅ **Answer: 500–599 (Server Error Responses)**

# 3. ⭐ Common HTTP Status Codes

```text
                COMMON STATUS CODES
                       │
        ┌──────────────┼───────────────┐
        ▼              ▼               ▼
       200            301             404            500
        │              │               │              │
        ▼              ▼               ▼              ▼
       OK       MOVED PERMANENTLY  NOT FOUND   INTERNAL SERVER
                                                  ERROR
```

### 🟢 200 — OK

**Meaning:** Request was successful.

```text
200 → SUCCESS ✅
```

---

### 🔄 301 — Moved Permanently

**Meaning:** The requested resource has been permanently moved to a new URL.

```text
301 → RESOURCE MOVED 🔄
```

---

### ❌ 404 — Not Found

**Meaning:** The requested resource could not be found on the server.

```text
404 → RESOURCE NOT FOUND ❌
```

### 📝 Exam Question

**Q. Which HTTP status code indicates that the requested resource could not be found?**

✅ **Answer: 404 (Not Found)**

---

### 🔴 500 — Internal Server Error

**Meaning:** The server encountered an unexpected problem while processing the request.

```text
500 → SERVER PROBLEM 🔴
```

---
