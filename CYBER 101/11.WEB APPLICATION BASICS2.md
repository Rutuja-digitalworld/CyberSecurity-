# HTTP Response — Cybersecurity GitHub Notes

## 1. Status Line

The Status Line is the first line of an HTTP response. It contains three parts:

```http
HTTP/1.1 200 OK
```

| Part     | Meaning       |
| -------- | ------------- |
| HTTP/1.1 | HTTP version  |
| 200      | Status code   |
| OK       | Reason phrase |

                    STATUS LINE
                         │
             ┌───────────┼───────────┐
             ▼           ▼           ▼
      HTTP VERSION   STATUS CODE   REASON PHRASE
             │           │           │
             ▼           ▼           ▼
          HTTP/1.1       200          OK
             │           │           │
             ▼           ▼           ▼
        HTTP version   Request      Short human-
                       result       readable meaning

### Q1. Which part provides the HTTP version, status code, and brief explanation?

**Answer: Status Line**

## 2. HTTP Status Code Categories

| Status code | Category      | Meaning                                     |
| ----------- | ------------- | ------------------------------------------- |
| 100–199     | Informational | Request is being processed.                 |
| 200–299     | Successful    | Request succeeded.                          |
| 300–399     | Redirection   | Resource moved or another action is needed. |
| 400–499     | Client Error  | Problem with the client's request.          |
| 500–599     | Server Error  | Problem on the web server.                  |

### Q2. Which category indicates an internal server issue?

**Answer: 500–599 (Server Error Responses)**

## 3. Common HTTP Status Codes

### 200

**OK**

Request successful.

**Success**

### 301

**Moved Permanently**

Resource moved to a new URL.

**Redirect**

### 404

**Not Found**

Requested resource does not exist at that URL.

**Client error**

### 500

**Internal Server Error**

Server encountered an unexpected problem.

**Server error**

### Q3. Which HTTP status code indicates that the requested resource could not be found?

**Answer: 404 (Not Found)**

## 🧠 Quick Memory Trick

```text
1xx → Information
2xx → Success
3xx → Redirect
4xx → Client Error
5xx → Server Error
```

**Remember:** Status Line = HTTP Version + Status Code + Reason Phrase.
