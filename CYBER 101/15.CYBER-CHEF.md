## 1. Operations Area

The **Operations Area** contains all the different things that CyberChef can do.

You can **search** for an operation and use it.

### Common Operations

| Operation           | Simple Meaning                                          |
| ------------------- | ------------------------------------------------------- |
| **From Morse Code** | Converts Morse code into normal letters.                |
| **URL Encode**      | Converts special characters in a URL into encoded form. |
| **To Base64**       | Converts normal text into Base64 format.                |
| **To Hex**          | Converts text into Hexadecimal values.                  |
| **To Decimal**      | Converts text into decimal numbers.                     |
| **ROT13**           | Changes letters by rotating them 13 positions.          |

### Easy example:

**To Base64**
<img width="757" height="512" alt="image (67)" src="https://github.com/user-attachments/assets/8301a348-5599-47cd-9402-617fe06f129c" />

```text
Hello
↓
SGVsbG8=
```

So basically:

**Input → Operation → Converted Output**

💡 You can also **hover over an operation** to see what it does and an example.

# 2. Recipe Area

The **Recipe Area** is where we put the operations we want to use.

<img width="388" height="680" alt="image (66)" src="https://github.com/user-attachments/assets/037657b7-8714-42c9-9e22-4adcd139470c" />

Think of it like a **step-by-step cooking recipe**.

For example:

```text
Input
 ↓
To Base64
 ↓
ROT13
 ↓
Output
```

You can:

* Add operations
* Remove operations
* Change their order
* Change their settings/options

### Important buttons:

**Save Recipe** → Saves your operations.

**Load Recipe** → Loads a previously saved recipe.

**Clear Recipe** → Removes all operations from the recipe.

### BAKE!

The **BAKE!** button tells CyberChef:

> "Now perform all these operations."

If **Auto Bake** is enabled, CyberChef automatically processes the input whenever you change something.

---

# 3. Input Area

The **Input Area** is where you give CyberChef the data you want to work on.

You can:

* Type text
* Paste text
* Upload a file
* Drag a file into it

### Important options:

**Add New Input Tab**
→ Opens another input area so you can work with another input.

**Open Folder as Input**
→ Uploads an entire folder.

**Open File as Input**
→ Uploads a file.

**Clear Input and Output**
→ Removes the current input and output.

**Reset Pane Layout**
→ Returns the CyberChef screen to its default layout.

# 4. Output Area

The **Output Area** shows the **final result** after CyberChef processes your input.

Example:

```text
Input:
Hello

Operation:
To Base64

Output:
SGVsbG8=
```
<img width="777" height="387" alt="image (69)" src="https://github.com/user-attachments/assets/352ae83b-8596-44d8-9dc7-e657a5820c50" />

### Output options:

**Save Output to File**
→ Saves the result as a `.dat` file.

**Copy Raw Output**
→ Copies the result so you can paste it somewhere else.

**Replace Input with Output**
→ Takes the output and puts it back into the Input area.

**Maximise Output Pane**
→ Makes the Output area bigger.

# TASK 3:WORKFLOW

Before using CyberChef, follow these **4 simple steps**:

### 1️⃣ Set Your Objective

First ask:

> **“What do I want to achieve?”**

Clearly decide what you want to find or do.

**Example:**
You found a strange/gibberish string during a security investigation and want to find out if it contains a hidden message.

---

### 2️⃣ Put Data in Input

Now give your data to CyberChef.

You can:

* **Paste** the data
* **Type** the data
* **Upload** a file

For our example, paste the **gibberish string** into the **Input** area.

---

### 3️⃣ Choose the Operations

Now decide:

> **“Which operation should I use?”**

This can be difficult if you don't know what type of data you have.

So, first **understand/research the data**, then choose the suitable operation.

For example, if you think the string may involve **encryption/encoding**, you can try operations such as:

* **ROT13**
* **Base64**
* **Base85**
* **ROT47**

These are available under the **Encryption/Encoding** category.

---

### 4️⃣ Check the Output

Finally, look at the result and ask:

> **“Did I achieve my objective?”**

* ✅ **Yes** → You're done!
* ❌ **No** → Try again from Step 1 and choose another suitable operation.

# TASK 4:HANDS ON PRACTICE:
## Q1. What is the hidden email address?

### Steps:

1. Open **CyberChef**.
2. Load the downloaded **Extractor `.txt` file** into the **Input** section.
3. On the left side, search for:
   **Extract email addresses**
4. Click/drag **Extract email addresses** into the **Recipe** section.
5. Look at the **Output** section.
6. Copy the email address shown there.
7. Submit that email as your answer.

**Answer:** `hidden@hotmail.com`

## Q2. What is the hidden IP address that ends in `.232`?

### Steps:

1. Remove/disable **Extract email addresses** from the Recipe.
2. In the left **Operations** search box, type:
   **Extract IP addresses**
3. Add **Extract IP addresses** to the Recipe.
4. Look at the **Output** section.
5. You may see more than one IP address.
6. Find the IP address that ends with **`.232`**.
7. Submit that IP address.

**Answer:** `10.10.2.10`

# Q4. What is the binary value of decimal number `78`?

This one does **not** require the downloaded file.

### Steps in CyberChef:

1. Remove the previous operation from the Recipe.
2. Search for **From Decimal**.
3. Add **From Decimal** to the Recipe.
4. In the **Input** box, type:

```text
78
```

5. Check the **Output**.

### Answer:

```text
01001110
```

# Q5. What is the URL encoded value of `https://tryhackme.com/r/careers`?

### Steps:

1. Remove the previous operation from the Recipe.
2. Search for:
   **URL Encode**
3. Add **URL Encode** to the Recipe.
4. In the **Input** box, paste:

```text
https://tryhackme.com/r/careers
```

5. Check the **Output** section.
6. Copy the encoded value.
7. Submit it.

### Answer:

```text
https%3A%2F%2Ftryhackme.com%2Fr%2Fcareers
```

The task specifically explains that `:` becomes `%3A` and `/` becomes `%2F` during URL encoding.
