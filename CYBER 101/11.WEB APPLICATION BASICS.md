# TASK 1:Web Application Components

## 1. Front End

* The **Front End** can be considered similar to the **surface of the planet**, the parts that an astronaut can see and interact with based on the laws of nature.
* A web application would have a user interact with it and use a number of technologies such as **HTML, CSS, and JavaScript** to do this.

### 1.1 HTML — Hypertext Markup Language

* **HTML** (Hypertext Markup Language) is a foundational aspect of web applications.
* It is a set of instructions or code that instructs a web browser on **what to display and how to display it**.
* It could be compared to simple organisms living on the planet; these organisms have **DNA**, which is the instructions for how simple organisms are put together.

### 1.2 CSS — Cascading Style Sheets

* **CSS** (Cascading Style Sheets) in web applications describes a **standard appearance**, such as:

  * Certain colours
  * Types of text<img width="291" height="462" alt="image (46)" src="https://github.com/user-attachments/assets/abc248c7-54ea-4f40-87c9-47b7ca95a4af" />

  * Layouts
* Continuing the analogy with DNA, these could be compared to the parts of DNA that describe the **colour, shape, size, and texture** of the simple organism.

### 1.3 JS — JavaScript

* **JS** (JavaScript) is part of a web application front end that enables **more complex activity in the web browser**.
* Whereas HTML can be considered a simple set of instructions on what to display, JavaScript is a more advanced set of instructions that allows **choices and decisions to be made on what to display**.
* In the planet analogy, JavaScript can be considered the **brain of an advanced organism**, which allows decisions to be made based on what and how something interacts with it.

# TASK2: Uniform Resource Locator (URL)

**Definition:** A URL is a web address that lets you access online content such as webpages, videos, photos, or other media.

---

## Anatomy of a URL

**Definition:** A URL consists of several parts, each playing a different role in helping you find and access the right resource.
<img width="1172" height="307" alt="image" src="https://github.com/user-attachments/assets/7586ede2-5a28-4818-96fe-5be17ab4521f" />

### Scheme

**Definition:** The scheme is the protocol used to access a website, such as HTTP or HTTPS.

### User

**Definition:** The user contains login details, usually a username, used to access resources requiring authentication.

### Host/Domain

**Definition:** The host or domain identifies the website being accessed and must be unique.

### Port

**Definition:** The port number directs the browser to the correct service on the web server, commonly 80 for HTTP and 443 for HTTPS.

### Path

**Definition:** The path points to the specific file or page on the server that you want to access.

### Query String

**Definition:** The query string starts with `?` and is used to pass information such as search terms or form inputs.

### Fragment

**Definition:** The fragment starts with `#` and points to a specific section of a webpage.
